# Proxifier

Reliable proxy client library for Go programs.

#### Features

* [X] TLS 
* [X] SOCKS4
* [X] SOCKS5
* [X] HTTP ``(HTTP FORWARD)``
* [X] HTTPS ``(HTTP TUNNEL)``
* [X] Auth
